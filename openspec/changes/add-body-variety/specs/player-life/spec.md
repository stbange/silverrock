# Spec Delta: player-life

## ADDED Requirements

### Requirement: Body at character creation
Character creation SHALL let the player choose the build, frame, height and chrome limbs, and the started character
SHALL have the chosen body.

#### Scenario: Choose the body
- **WHEN** the player cycles the build, frame, height and chrome on the creation screen and starts
- **THEN** each label changes with its choice, the preview shows the new body, and the player character has it
