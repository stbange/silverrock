# Building interiors

Every building can be entered. These views are from just inside the front door of one building of each kind, rendered
by `test_civilian_interiors` in the platform tests (`SR_INTERIOR_SHOTS=dir`).

| File | Shows |
|---|---|
| `shop.png` | A shop: shelves along the walls and behind the counter, the keeper at the till |
| `food.png` | A noodle bar: stools at the counter, tables, people eating |
| `bar.png` | A bar: the long neon bar with bottles, stools, the bartender, pink light |
| `bar_panic.png` | The same bar after a shot: everyone ducks or covers their head |
| `clinic.png` | A clinic: the white waiting room and the reception desk, wards behind |
| `capsule.png` | A capsule hotel: reception and stacked, glowing pods |
| `fixer.png` | A fixer: the dim front room, the back room with the fixer's table |
| `booth.png` | A Matrix booth hall: booths with screens along the wall |
| `residential.png` | A residential lobby: the door to the corridor of flats; mailboxes and the lift at the sides |
| `office.png` | An office: reception, open-plan desks beyond |
| `warehouse.png` | A warehouse: an open hall of crates and racks |
| `civic.png` | A civic front desk (police, city hall or media) |
